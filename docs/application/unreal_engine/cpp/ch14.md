## 139 Blueprint Native Event

BlueprintNativeEvent 允许你在 C++ 中为一个函数提供一个默认实现，同时允许在子类的蓝图中覆盖（重写）这个函数，从而实现 C++ 逻辑与蓝图灵活性的结合

在实现 C++ 默认逻辑时，需要实现一个名为 `FunctionName_Implementation()` 的函数。引擎的反射系统会自动处理好调用关系
